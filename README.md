# APIC Community

Community page of **APIC** (All Purpose Integrated Components): a C++ real-time engine and tool set for
simulators, test benches, hardware / software in the loop rigs and embedded systems.

## Here you can

- **Ask a question**: open a [Discussion](../../discussions).
- **Report a problem**: open an [Issue](../../issues/new/choose) with the *Bug report* form.
  Include the APIC version, the operating system and the text the CoreEngine printed.
- **Suggest a feature**: the *Feature request* form in Issues.
- **Share a tip**: the *Tip or trick* form in Issues, or a pull request to [`tips/`](tips/).
- **Download a sample project**: [Releases](../../releases). What each sample shows: [`samples/`](samples/).
- **Share a sample**: a pull request to [`samples/`](samples/).
